# Tableau Visualizations

## Overview
This project uses Tableau to visualize patterns in housing burden and insurance expenditures using Consumer Expenditure Survey data from the U.S. Bureau of Labor Statistics.

The visualizations complement the project's Excel, SQL, R, Python, and Power BI components by presenting descriptive findings in a visual format.

## Visualizations

### Average Housing Burden by State
A geographic map displaying average housing burden across states. The map uses a color gradient to represent differences in average housing burden.

### State Housing Burden Comparison
A bar chart comparing average housing burden across states. The chart supports comparisons of housing burden between geographic areas.

### Quarterly Housing Burden Trends
A line chart examining changes in average housing burden over time, where the available data support a verified chronological ordering.

### Quarterly Insurance Expenditure Trends
Separate line charts examining insurance expenditure patterns over time, where completed and supported by the available data.

## Tools
- Tableau
- Consumer Expenditure Survey data

## Data Source
U.S. Bureau of Labor Statistics, Consumer Expenditure Survey.

The underlying dataset is not included in this repository.

## Limitations
The visualizations are descriptive and do not establish causation.

State comparisons depend on accurate state-code mappings and the availability of observations for each state. Quarterly trend visualizations depend on correctly identifying and ordering the available time periods.
