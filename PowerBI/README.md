# Power BI Dashboard

## Overview
This project uses Power BI to explore patterns in housing burden, vehicle insurance expenditures, and household characteristics using Consumer Expenditure Survey data from the U.S. Bureau of Labor Statistics.

The dashboard provides a visual summary of the data and allows users viewing the original dashboard to explore patterns across selected household characteristics.

## Dashboard Components

### Key Performance Indicators (KPIs)
The dashboard includes summary cards displaying:
- Average adjusted vehicle insurance expenditures
- Average housing burden
- Average family size
- Number of observations with available housing burden values

### Visualizations
The dashboard includes:
- **Housing Burden and Adjusted Vehicle Insurance Expenditures:** A scatter plot displaying the distribution of vehicle insurance expenditures across housing burden values.
- **Housing Burden and Adjusted Health Insurance Expenditures:** A scatter plot comparing housing burden with health insurance expenditures.
- **Vehicle-Related Expenditures:** A comparison of average adjusted vehicle insurance expenditures, gas and motor oil expenditures, and vehicle finance payments.

### Interactive Filters
The dashboard includes slicers for selected household characteristics and survey variables, including housing tenure, state, family size, marital status, and QSQ118.

## Tools
- Microsoft Power BI
- Consumer Expenditure Survey data

## Data Source
U.S. Bureau of Labor Statistics, Consumer Expenditure Survey.

The underlying dataset is not included in this repository.

## Limitations
The dashboard presents descriptive statistics and visual patterns. The scatter plots do not establish causation or independently determine statistical significance.

Regression analysis is conducted separately to investigate the relationship between housing burden and insurance expenditures while accounting for other variables.
