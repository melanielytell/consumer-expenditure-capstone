# Consumer Expenditure Capstone Project

## Project Overview
This project analyzes data from the U.S. Bureau of Labor Statistics Consumer Expenditure Surveys to examine the relationship between housing burden and vehicle insurance expenditures. It combines data cleaning, descriptive statistics, database queries, statistical modeling, and data visualization to explore consumer expenditure patterns.

## Research Objective
The primary objective is to investigate the relationship between housing burden and vehicle insurance expenditures while accounting for household characteristics, demographic factors, and other expenditure-related variables.

## Data Source
The data were obtained from the U.S. Bureau of Labor Statistics Consumer Expenditure Surveys Public-Use Microdata.

The dataset was cleaned and prepared for analysis by selecting relevant variables and removing identification fields.

**Data source:** [BLS Consumer Expenditure Survey Public-Use Microdata](https://www.bls.gov/cex/pumd.htm)

## Tools and Technologies
This project uses the following tools:

- **Microsoft Excel:** Descriptive statistics, pivot tables, and charts.
- **SQL:** Data queries, grouped summaries, and comparisons across housing-burden categories.
- **R:** Regression modeling, diagnostic testing, and heteroskedasticity-robust standard errors.
- **Python:** Data analysis and programming.
- **Power BI:** Data visualization and dashboard development.
- **Tableau:** Data visualization and exploration of expenditure patterns.
- **GitHub:** Code organization, project documentation, and version control.

## Methodology

### 1. Data Preparation
Relevant variables were selected from the original dataset, and the data were prepared for analysis. Identification fields were removed from the working dataset.

### 2. Excel Analysis
Summary statistics, pivot tables, and charts were used to explore the dataset and compare expenditure patterns across selected categories.

### 3. SQL Analysis
SQL queries were used to group observations, calculate summary measures, and examine differences across housing-burden categories.

### 4. Statistical Analysis in R
Regression models were developed to examine the relationship between housing burden and the logarithm of adjusted vehicle insurance expenditures while controlling for selected household and demographic characteristics. Diagnostic tests were also used to evaluate model assumptions.

### 5. Python Analysis
Python was used for additional data analysis and programming practice.

### 6. Power BI and Tableau
Interactive visualizations and dashboards were developed to explore housing burden, household characteristics, and expenditure patterns.

## Research Focus
The analysis focuses on housing burden and adjusted vehicle insurance expenditures. Additional variables are included to account for differences in household composition, demographic characteristics, housing tenure, and other expenditure-related factors.

## Limitations
- The analysis is limited to the variables available in the selected dataset.
- The survey quarter was not retained in the cleaned dataset, limiting the ability to conduct chronological analyses using that field.
- Regression results identify statistical associations and should not automatically be interpreted as causal relationships.
- The findings are specific to the analytical sample and model specifications used.

Project files are organized by analytical tool and include scripts, spreadsheets, queries, visualizations, and documentation as available.
